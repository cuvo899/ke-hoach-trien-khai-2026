Dữ liệu dùng chung cho team

File HTML tự thân chỉ lưu trên từng trình duyệt. Để một người cập nhật và cả team nhìn thấy, cần kết nối API/Database nội bộ. Dashboard đã hỗ trợ GET để kéo dữ liệu và PUT để lưu toàn bộ dữ liệu.
API cần cho phép CORS từ trình duyệt. GET trả về mảng hạng mục hoặc {tasks:[...]}; PUT nhận {project,tasks,audit,updatedAt}.
